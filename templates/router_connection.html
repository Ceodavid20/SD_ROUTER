Existing polling clients

Existing V1/V2 polling and acknowledgement continue to use their provisioned identities.

  1. Configure an approved controller address that the router can reach, with verified HTTPS for network use.
  2. Provision the router identity and its own authentication key outside the browser. The controller accepts only authorized registered identities.
  3. Transfer the private RouterOS client and public CA certificate through the approved management channel. Verify the certificate fingerprint and the router clock, then run the client once.
  4. Check the router list for an authenticated check-in and a recorded response receipt. A receipt confirms communication; the current client issues no routing changes.
